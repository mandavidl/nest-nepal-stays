# Nepal Stays

Create a modern, professional, fully responsive accommodation rental and booking website called “NestNepal” (name can be changed later).



CONCEPT:

NestNepal is a Nepal-focused accommodation marketplace connecting guests with property owners. Users can search, compare, and book places to stay, while hosts can list and manage their properties.



The website is inspired by Airbnb but must have its own branding and design. Its main advantage is ORGANIZATION: different accommodation types must be clearly separated instead of being mixed together.



IMPORTANT:

Focus ONLY on accommodation and property rentals. Do not add tours, restaurants, travel guides, transportation, activities, social media, or unrelated features.



ACCOMMODATION CATEGORIES:

1. Homes & Apartments

2. Hotels

3. Private Rooms

4. Homestays

5. Cottages & Cabins



Users should be able to select a category before browsing. Clearly display the property type on every listing.



DESIGN:

Create a clean, premium, modern interface with warm neutral colors, white cards, subtle shadows, attractive property photos, clear typography, and generous spacing. Make it trustworthy and easy to navigate. Do not copy Airbnb's exact branding or design.



Use subtle animations such as card hover effects, smooth transitions, image transitions, and section fade-ins. Avoid excessive animations.
